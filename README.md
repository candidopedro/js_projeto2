# 🧪 Projeto de Testes — HTML, CSS & JavaScript

Projeto inicial para prática e experimentação com as tecnologias fundamentais da web: **HTML**, **CSS** e **JavaScript**.

---

## 📁 Estrutura do Projeto

```
projeto/
├── index.html        # Página principal
├── css/
│   └── style.css     # Estilos da aplicação
├── js/
│   └── script.js     # Lógica e interatividade
└── README.md         # Documentação do projeto
```

---

## 🚀 Como Usar

1. Clone ou baixe este repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd seu-repositorio
   ```

3. Abra o arquivo `index.html` diretamente no navegador, ou use uma extensão como o **Live Server** (VS Code) para visualização em tempo real.

## 🎯 Objetivo

Este repositório serve como ambiente de testes e aprendizado. Aqui você pode:

- Praticar conceitos básicos e avançados de HTML, CSS e JS
- Testar pequenos experimentos sem comprometer outros projetos
- Documentar o progresso nos estudos

---

## 📌 Observações

- Este projeto **não possui dependências externas** — basta um navegador moderno para rodar.
- Ideal para iniciantes que estão dando os primeiros passos no desenvolvimento web.
- Fique à vontade para modificar, quebrar e reconstruir à vontade — é só para testes! 😄
